# ИИ в КлиентРадаре — как включать

## Быстрый путь (24.10): тот же ИИ, что в боте модерации
Владелец подключил ИИ в боте модерации (GigaChat / YandexGPT / своя модель). CRM-бот умеет работать с тем же ИИ и теми же ключами.

1. Скопировать строки ИИ из .env бота модерации в .env CRM (ключи на экран не выводятся):
```
grep -E '^(AI_PROVIDER|GIGACHAT_|YANDEX_|LOCAL_AI)' /root/tg-group-bot/.env >> /root/CRM-bot-tg/.env
```
2. Обновить и перезапустить CRM: `cd ~/CRM-bot-tg && git pull && docker compose up -d --build`
3. В боте: команда `/aitest` — «✅ ИИ на связи: …». В «🧪 Самопроверке» строка «ИИ-помощник» с названием ИИ.
4. Что делает ИИ сразу: фильтр «заказчик или исполнитель» и помощник в спорных случаях (флаги `ai_classify`, `ai_decide` = 1).
   Черновики ответа — включить ⚙️ → ✨ ИИ → «ИИ-черновики» = 1. Выбрать ИИ вручную — там же «Какой ИИ».
5. Своя модель (`LOCAL_AI=1`) доступна CRM, только если он в общей сети с ботом модерации (docker-compose.web.yml уже подключает).

## Что уже готово в коде (ничего не тратится, пока выключено)
- Кнопка «✨ Черновик ответа» под заявкой. Без ключа и при `ai_enabled=0` — простой бесплатный черновик по правилам (`services/draft.py`).
- Модель по умолчанию — **Haiku 5.5** (самая дешёвая). Если в настройках окажется неизвестная модель, берётся тоже самая дешёвая.
- Лимиты в сутки: 3 для бесплатных, 30 для платных (⚙️ → ✨ ИИ). Размышление на минимуме, ответ до 1000 токенов.
- Каждый запрос записывается (модель, токены); в 📊 Статистике админа видна строка «✨ ИИ за 30 дней».
- В ИИ уходит только текст заявки (без имени, ника, ID автора и названия группы) + ниша, цены и шаблон самого пользователя.
- Команда админа `/aitest` — сравнить Haiku и Sonnet на ваших последних заявках (платно, с подтверждением; без ключа ничего не тратит).

## Цены (за 1 млн токенов, вход / выход; на 6.10.2026 — проверьте на сайте Anthropic)
| Модель | Цена | Один черновик (грубо) |
|---|---|---|
| Haiku 5.5 | $0,10 / $0,50 | около $0,0003 |
| Sonnet 5.5 | $2 / $10 | около $0,006 (≈ в 20 раз дороже) |
| Opus 5.5 | $4 / $20 | около $0,011 (≈ в 40 раз дороже) |
Рекомендация: Haiku для всех. Sonnet — по желанию платным. Opus для этих задач не нужен.

## Когда включать
Когда есть живая аудитория (например, 20–50 активных пользователей) и люди сами просят «умнее» черновики. До этого правила бесплатны и достаточны.

## Шаги включения (с телефона)
1. Заведите аккаунт на console.anthropic.com, создайте ключ API. Ключ никому не показывайте и в чат не присылайте.
2. В консоли поставьте небольшой месячный лимит расходов (раздел с лимитами/биллингом), чтобы нельзя было потратить больше задуманного.
3. На сервере впишите ключ в `.env` (откройте `nano ~/CRM-bot-tg/.env`, добавьте строку `ANTHROPIC_API_KEY=ваш_ключ`, сохраните: Ctrl+O, Enter, Ctrl+X). В чат ключ не отправляйте.
4. Перезапуск: `cd ~/CRM-bot-tg && docker compose up -d`
5. Проверка качества: в боте `/aitest` → «Запустить» (примерно $0,01–0,10). Сравните Haiku и Sonnet на реальных заявках.
6. ⚙️ Настройки → ✨ ИИ: «Claude (1/0)» = 1; «Модель ИИ» — по результату проверки (по умолчанию Haiku); при необходимости поправьте лимиты.
7. Добавьте в политику конфиденциальности абзац (ниже).
8. Следите: 📊 Статистика → «✨ ИИ за 30 дней» и расходы в консоли Anthropic.

## Абзац для политики (добавить при включении)
«Если включена функция ИИ-черновика, текст заявки (без имени, ника и ID автора), а также ниша, цены и шаблон ответа пользователя передаются в сервис Anthropic (Claude) для составления черновика ответа. Данные используются только для этого запроса.»
(Условия обработки данных у Anthropic уточните на их сайте.)

## Как быстро выключить
⚙️ Настройки → ✨ ИИ → «Claude (1/0)» = 0 — мгновенно, бот вернётся к бесплатному черновику. Полностью: удалить строку `ANTHROPIC_API_KEY` из `.env` и выполнить `docker compose up -d`.

## Если расходы выросли
Уменьшить «ИИ в сутки» для бесплатных и платных; убедиться, что модель — Haiku; посмотреть число запросов в статистике.
