# Партнёрство с группами

Решение владельца 24.11.2026: 20% внутренними кредитами с оплаченных подписок и рекламы пользователей по ссылке группы. Ставка board_percent=20 управляется настройками; 1 кредит = 1 ₽ внутри сервиса, округление вниз. Денежного вывода нет. Кредиты расходуются на дни подписки и коды модерации из доступного запаса; оплату рекламы кредитами не обещаем.

Привязка: users.source=g<ID>, получатель Group.board_admin. Самоначисление исключено. Комиссия с рекламы записывается в одной транзакции с успешной оплатой/очередью постов. Бесплатные, отменённые заказы и лишние платежи для возврата не награждаются. Повторная обработка не начисляет снова. На refund_days комиссия заморожена. Полные/частичные возвраты отменяют соответствующую долю; после расходования доступный баланс не уходит в минус, ранее потраченное не взыскивается. Учёт возвратов не заменяет подтверждения провайдера.

Отчёт: 👤 Профиль → 💰 Мои кредиты → 📊 Партнёрский отчёт. Количество оплат подписок/рекламы, валовая сумма, возвраты, остаток выручки сервиса, начисленная/отменённая комиссия и общий баланс. Оплаты относятся к партнёру по записанной комиссии, а не текущему владельцу группы. Старые оплаты без комиссии ретроспективно не добавляются. Регистрации — текущее число пользователей с источником группы. Сумма оплат не является денежным доходом партнёра.

Проверены публичные описания 50 групп, найдены 9 подходящих контактов для адресного предложения; Дагестан первый. Контакт для сотрудничества не доказывает владение. Перед отправкой проверяем предыдущую переписку и отказы. Одно предложение, без рассылки участникам и повторов. Права рекламных публикаций не меняем. Отправка и ответы фиксируются отдельно после проверки выкладки.

Проверка: 92 профильных теста локально; полный CI SQLite/PostgreSQL перед выкладкой. Схема базы не меняется.
