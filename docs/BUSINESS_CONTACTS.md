# Деловые контакты Дагестана — 24.11.2026

Запрос владельца: отдельный личный список контактов региона для обращений. Реализована первая версия для опубликованных деловых Telegram-контактов, не база всех людей Дагестана. Личные номера, участники групп и личные аккаунты по региону не перечисляются.

Открыть: 🛠 Управление → 📇 Контакты Дагестана (кнопка только OWNER_IDS). Обычные администраторы и групповые callback не получают доступ к данным/CSV. Поиск читает og:description известных публичных групп Дагестана, извлекает @контакты только рядом с явным указанием обращения по вопросам, рекламе, сотрудничеству, заказам/записи или к администратору. Каждая запись содержит источник, опубликованный контекст и дату проверки. Регион относится к источнику; место проживания и личная активность человека не проверены. Это кандидаты для делового обращения, не доказательство права собственности или согласия на рассылку.

Список без дублей по нормализованному @имени, до 500 контактов/5 источников каждый, до 100 известных источников за проход. Новые, Написал, Ответили, Отказ, Отложены; ручная отметка после отправки. Повторный поиск не сбрасывает отказы и статусы; старые одноразовые журналы обращений в /srv/data/partner_inquiries читаются только для защиты от повторов. Для отказов кнопка открытия чата скрыта; возврат в новые с подтверждением. Возможны остановка после текущего источника и CSV со ссылками и защитой от формул. Нет автоматической отправки сообщений и новых Telegram-сессий. Внешние платные API не подключаются.

Поиск по HTTPS только t.me/<валидный username>, без переходов/редиректов, 8 секунд на источник, максимум 256 КБ; ошибки отражаются в отчёте. Один поиск за раз; интервал 10 минут. Найденное сохраняется после каждого источника. История не стирается при недоступности страницы. Источник, исчезнувший из нового прохода, не делает контакт активным; смотрите дату проверки.

Хранение: существующая settings, служебный JSON ключ dagestan_business_contacts_v1; структура БД не меняется. Повреждённый JSON не перезаписывается. Новые данные входят в штатные копии БД. Два async-замка разделяют поиск и изменения списка. Откат — предыдущий CRM-образ штатным способом, JSON не удалять. Modexa, реклама и разведчик не изменяются.

Проверено локально: 20 тестов (новые 7 + партнёрский отчёт/кредиты), компиляция и git diff --check. Полный CI SQLite/PostgreSQL и установка проверяются отдельно. Тесты не отправляют сообщения людям. Не заявлять «все активные контакты региона»: первая версия ограничена известными публичными источниками, а не всем интернетом.
