Текущий пакет без изменения базы: единый services/lead_time.found_label для Telegram-карточек и API кабинета. Заметная точная дата с годом, время МСК (Дагестан), сегодня/вчера и возраст в минутах/часах/днях. Нет времени — честная подпись, будущая дата — пометка о проверке времени. Ни дату доставки, ни время обнаружения не называем публикацией. Подпись: «Дата публикации не сохранена. Если оригинал доступен, посмотрите дату в нём». Старые сообщения Telegram массово не редактируются: откройте заявку заново из списка. В кабинете перезагрузите экран.

«Новые» — ещё не разобранные пользователем, а не обязательно свежие; пояснение есть в боте и кабинете. Порядок и статусы заявок не изменены. Обычная карточка называется «Заявка», а не «Новый клиент». Признак горячей заявки по тексту не является проверкой свежести.
