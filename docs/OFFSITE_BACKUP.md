## Будущее восстановление

Только по новому прямому запросу владельца. Получить архивы/сертификат из Release и ключ из приватного Notion, сравнить SHA256 с каноническими значениями в приватной записи. Расшифровка:

```bash
openssl cms -decrypt -binary -inform DER -in crm-retired-20261124.tar.gz.cms -recip recipient-cert.pem -inkey CRM-recovery-key-20261124.txt -out crm-retired-20261124.tar.gz
```

Образы — аналогично с входом crm-images-20261124.docker.tar.gz.cms. В tar есть offsite-manifest.json и offsite-export-plan.json; сначала проверка целостности и отдельное восстановление данных, затем отдельное решение о запуске. Не выводить .env, SQLite, контейнерные/Compose-конфигурации или сессии Telegram в чат/публичные логи. Не возвращать старое условие deploy без отдельной проверки и нового запроса.
