# Включение мини-приложения — по шагам (с телефона, Termius)

Нужно один раз. Если что-то не получилось — бот продолжает работать как раньше, кабинет просто не показывается.

## 1. Узнать адрес сервера
```
curl -4 ifconfig.me
```
Получите IP, например `203.0.113.5`. Бесплатный адрес из него: заменить точки на дефисы и добавить `.sslip.io` → **`203-0-113-5.sslip.io`**
(так сертификат выдаётся без покупки домена). Запомните его — ниже это `ВАШ_АДРЕС`.

## 2. Открыть порты 80 и 443
- В панели Selectel: у сервера «Irene» → Фаервол / Группы безопасности — разрешить входящие TCP **80** и **443**.
- Если на сервере включён ufw:
```
sudo ufw allow 80/tcp && sudo ufw allow 443/tcp
```
Проверка, что порты никто не занял: `sudo ss -ltnp | grep -E ':80 |:443 '` — вывод должен быть пустым.

## 3. Записать настройки в `.env` (на сервере)
```
cd ~/CRM-bot-tg
printf '\nWEBAPP_HOST=ВАШ_АДРЕС\nWEBAPP_URL=https://ВАШ_АДРЕС\nCOMPOSE_PROFILES=web\n' >> .env
```
Подставьте свой адрес вместо `ВАШ_АДРЕС`. Ключи и токены никуда вписывать не нужно.

## 4. Обновить и запустить
```
cd ~/CRM-bot-tg && git pull && docker compose up -d --build
sleep 30 && docker compose ps && docker compose logs --tail 20 caddy
```
В `ps` должны быть два сервиса: `bot` и `caddy`. В логе caddy — строки про `certificate obtained successfully` (первый раз до минуты).

## 5. Проверить
- С телефона откройте в браузере `https://ВАШ_АДРЕС/healthz` — должно показать `{"ok": true}`.
- В боте отправьте `/app` или откройте 👤 Профиль → **📱 Кабинет** — откроется окно с вашим именем, тарифом и цифрами заявок.

## Если не работает
- Сертификат не выдался (в логе `caddy` ошибки `acme`/`timeout`): порты 80/443 закрыты — вернитесь к шагу 2.
- `healthz` открывается, а в боте «Откройте кабинет из бота»: открывайте кабинет только кнопкой в боте, не ссылкой из браузера.
- Память: `free -m` — после запуска свободно должно оставаться >100 МБ (с учётом swap).
- Отключить кабинет: удалить три строки из `.env` и выполнить `docker compose up -d --remove-orphans`.
