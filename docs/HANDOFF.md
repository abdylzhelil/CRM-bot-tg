## 1. Что это
**КлиентРадар** (@klientradarbot) — Telegram-бот: находит заявки от клиентов в открытых группах и раздаёт их пользователям
по нишам и городам, плюс CRM (клиенты, напоминания, статистика). Репозиторий `abdylzhelil/CRM-bot-tg`.
Второй бот — модерации (`abdylzhelil/tg-group-bot`) — **не трогать**, он только «разведчик» (передаёт сообщения).

## 2. Правила владельца
- Общение по-русски, просто, шагами, с готовыми командами (владелец сидит с телефона: Termius + Telegram).
- Ключи/токены/пароли/коды из SMS не просить и не показывать.
- Бот модерации не менять (лицензию в нём — только с явного разрешения). Никаких чужих аккаунтов, сбора ников и номеров; только открытые группы.
- Заявки делим **по количеству поровну**, не «форой по времени»; внутри одной общей заявки — очередь с интервалом `share_gap_min`=2 мин
  (первым автор группы, затем выше уровень, затем меньше заявок за сутки).
- Claude (ИИ) пока **не подключаем** (боязнь расходов): черновик ответа по правилам, бесплатно. Код Claude есть, выключен (`ai_enabled`=0).
- Не создавать PR без просьбы. Ветка на сервере `ccr-a042c0a9-cjx9fv`.

## 3. Сервер и обновление
Selectel «Irene» (Алматы), Ubuntu 24.04, 1 ГБ RAM + swap, оплата почасовая. CRM в `/root/CRM-bot-tg`, бот модерации в `/root/tg-group-bot`.
Обновить CRM:
```
cd ~/CRM-bot-tg && git pull && docker compose up -d --build
sleep 20 && docker compose logs --tail 15
```
После запуска владельцу приходит «🟢 Бот запущен». Если нет — смотреть лог (ищем `Traceback`, `NameError`).
Тесты: `pytest` (144). Коммит делаем в `ccr-2183ec25-w59v36` и пушим в обе ветки:
`git push -u origin ccr-2183ec25-w59v36 && git push origin ccr-2183ec25-w59v36:ccr-a042c0a9-cjx9fv`.
