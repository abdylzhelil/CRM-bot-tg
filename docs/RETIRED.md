[Выполненная операция](https://github.com/abdylzhelil/CRM-bot-tg/actions/runs/45420836412), 24.11.2026 15:02 UTC:

- GitHub CI deploy выключен явным условием false; обычные push не выкладываются. Разовая задача удаления и прежняя SSH-диагностика также выключены.
- Проверены репозиторий, ветка, Compose с единственной CRM-службой bot, Docker project/working_dir и собственный bind /srv/data. Снят серверный flock CRM.
- SQLite backup API: копия до остановки с integrity_check и проверкой таблиц users/payments/settings. После штатной остановки сделана и проверена финальная копия, сохранён SHA256.
- Отключена restart policy только CRM-контейнера, затем он остановлен и удалён по точному ID. Compose down и Docker prune не применялись.
- Активный /root/CRM-bot-tg отсутствует. Каталог целиком перемещён в /root/crm-retired/CRM-bot-tg-<UTC>/app; указатель /root/crm-retired/latest-path содержит фактический путь. Закрытый родитель 0700, снимки/служебные записи 0600, .env не изменена. В архиве сохранены база, медиа, местные файлы, настройки и Git-каталог. Это закрытый архив на VPS, не GitHub.

Результат: crm_container_absent=true, crm_active_path_absent=true, archive_saved=true, other_containers_unchanged=true. Бот перестаёт отвечать после остановки polling; аккаунт Telegram/BotFather не удалялся.

На сервере gh-auth для изменения repository variable недоступен. Значение CRM_AUTO_DEPLOY_ENABLED не подтверждено как false и может оставаться прежним; запуск заблокирован явным false в workflow и отсутствием активного пути.
