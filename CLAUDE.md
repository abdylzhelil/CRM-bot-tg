# CRM-bot-tg — заметки для продолжения работы

Владелец общается по-русски, с телефона (Termius + Telegram). Объяснять просто, по шагам, с готовыми командами.
Ключи, токены, пароли в чат не просить и не показывать.

## Главные правила
- **Бот модерации (`abdylzhelil/tg-group-bot`) не трогать**: всё, что в нём сделано, не менять и не удалять,
  он должен работать как раньше. Единственное наше дополнение там — `bot/core/crm_feed.py` (передача сообщений
  в CRM, выключено без `CRM_FEED_URL`/`CRM_FEED_TOKEN`). Всё новое по продажам/клиентам — только в CRM-боте.
- Боты разные, но помогают друг другу: бот модерации — «разведчик» для CRM (передаёт сообщения групп,
  которые владелец включил в CRM: 🛠 Управление → 🔍 Группы → 🛡 Бот модерации).
- Никаких чужих аккаунтов пользователей, никакого сбора ников/номеров людей, только открытые группы.
- Рабочая ветка в обоих репозиториях: `ccr-a042c0a9-cjx9fv` (на сервере стоит она).

## Сервер
- Selectel, сервер «Irene», Алматы, Ubuntu 24.04, 1 ГБ RAM + 2 ГБ swap. Оплата почасовая — следить за балансом.
- CRM: `/root/CRM-bot-tg` (SQLite в `data/`), бот модерации: `/root/tg-group-bot` (Postgres, Redis, backup, monitor).
- Общая сеть Docker `tgbots`; CRM доступен боту модерации как `http://crm:8090` (секрет FEED_TOKEN / CRM_FEED_TOKEN).
- Обновление CRM: `cd ~/CRM-bot-tg && git pull && docker compose up -d --build`
- Вход по SSH только по ключу (пароль выключен).

## Что сделано в CRM-боте
- Многопользовательский режим: регистрация (ниши → город → заявки за сутки), у каждого свои ниши/город/минус-слова/
  тишина/шаблон/цены/заявки (`deliveries`)/CRM. Тарифы: free (5/день, задержка 30 мин) и full (выдаёт админ).
  Одну заявку получают ≤5 пользователей (платные первыми), админы — все. Спам-голоса: 3 или админ → общий ЧС.
- Источники заявок: разведчик (Telethon, ключи api_id/hash в `.env`, аккаунт добавлен), бот в группах
  (privacy mode off), бот модерации (feed). Общая база: где уже есть наш бот — другой не вступает.
- Разведчик: поиск групп → одно сообщение «найдено N» → отбор списком; пауза/стоп; до 10 вступлений в день;
  группы в папках «🔍 Разведка», звук выключен; ротация.
- Меню: сворачиваемая клавиатура, админские разделы в «🛠 Управление», команды в кнопке «Меню», фолбэк на меню.
- Обновление базы без потери данных: `app/migrate.py` (добавляет новые колонки сам).
- Тесты: `pytest` (72), общая обвязка в `tests/conftest.py` (`maker`, `tgbot`, `make_user`).

- Этап 2 сделан: 🌐 Каталог (`handlers/catalog.py`, `submissions.py`, `services/catalog.py`): ссылка → проверка через Bot API →
  ниша → город → одобрение админом (🔍 Группы → 📝 От пользователей) → каталог. Бонус +1 день 💎 за каждые N (`bonus_leads`)
  заявок из группы автора. Открытые каналы: `scout/channels.py` (опрос `t.me/s/`, заявка — только если в посте есть @контакт).
  Группы: колонки `kind`, `submitted_by`, `catalog`, `category_id`, `last_post_id`, `bonus_rewarded`; статусы `draft/pending/rejected`.

- Этап 3 сделан: рефералы (`services/referrals.py`, `plans.py`; награда +`ref_days` обоим после настройки приглашённого,
  `ref_percent`% пригласившему от бонусных дней приглашённого за группы) и «📨 Коллеге» (`leads.pass_to`, `Delivery.from_user`).
  Процент от **оплат** приглашённого — только когда появится оплата (этап 5). Колонки: `users.referred_by/ref_rewarded`, `deliveries.from_user`.

- Этап 4 сделан: заявки делятся **поровну по количеству, не по времени** (`distribute.recipients`: k = ⌈людей / заявок ниши за
  сутки⌉ с наименьшей нагрузкой за сутки; много заявок — у всех разные, мало — одинаковые). Автор группы из каталога всегда получает
  заявки своей группы сразу и мимо лимита. Уровни и рейтинг: `services/levels.py` (`users.level`), «🏆 Рейтинг» в каталоге.
  Владелец явно НЕ хочет «форы по минутам» — не возвращать.
