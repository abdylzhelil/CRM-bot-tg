# CRM-bot-tg — Telegram-бот «Менеджер продаж»

Личный инструмент для поиска клиентов в Telegram-группах: аккаунт-разведчик (Telethon) читает группы,
бот-менеджер (aiogram 3) присылает заявки, ведёт CRM и настройки. Реализован **Этап 1 (MVP)** из ТЗ.

## Что есть
- **Разведчик**: поиск публичных групп по запросам, карточки «Вступить/Пропустить» (режим `semi`) или автовступление (`auto`),
  чтение сообщений (только чтение, в группы не пишет), лимиты вступлений в сутки, случайные паузы, FloodWait,
  ротация (выход из групп без заявок), прокси на аккаунт, алерт при вылете сессии, авто-переподключение.
- **Триггеры**: слова-намерения + слова категории или сильная фраза, минус-слова; морфология (pymorphy3) —
  «сайт» находит «сайта», «сайтом». Недвижимость фильтруется по городу (по умолчанию Махачкала).
- **Антиспам**: скоринг 0–100 (аккаунт, поведение, текст), общий чёрный и белый списки, антидубли.
- **Уведомления** с кнопками: Ответить / В работу / Отложить / Отказ / Спам / Это клиент.
- **CRM**: карточки клиентов, этапы (новый → переговоры → думает → оплата → выполнено/отказ), заметки, бюджет,
  телефон, напоминания, поиск и фильтры.
- **Категории и слова** редактируются из бота; **статистика** и вечерний отчёт; **несколько аккаунтов-разведчиков**
  добавляются командой из бота (⚙️ Настройки → 👤 Аккаунты).

Этапы 2–3 (ИИ-классификация и черновики на Claude, режим тишины, Telegram Business, мультипользовательность) — в планах.

## Многопользовательский режим
Любой человек может пользоваться ботом: `/start` → выбор ниш → выбор города → сразу заявки за последние сутки.
- У каждого свои ниши, город, минус-слова, режим тишины, шаблон ответа и цены, свои заявки и своя CRM.
- Заявки делятся между пользователями поровну (не больше 5 получателей на заявку, ⚙️ Настройки) — платные первыми; администраторы получают все.
- 🆓 Бесплатный тариф: до 5 заявок в день с задержкой 30 минут. 💎 Полный: сразу и без лимита.
  Тариф выдаёт администратор: 👥 Пользователи → пользователь → 💎.
- «🚫 Спам» скрывает автора для этого пользователя; от администратора или 3 голосов — общий чёрный список.
- Администраторы — Telegram ID из `OWNER_IDS`. Старые заявки и клиенты при обновлении остаются у администратора.

## Бот в группах (без аккаунта-разведчика)
Бот-менеджер можно добавить в группу как участника — он молча читает сообщения и присылает заявки.
1. @BotFather → `/setprivacy` → выберите бота → **Disable** (иначе бот видит только команды; админам группы это не нужно).
2. 🔍 Группы → «➕ Добавить бота в группу» (или попросите админа группы добавить бота).
3. Бот сообщит о добавлении; заявки идут тем же путём: триггеры → антиспам → антидубли → карточка.

## Связь с ботом модерации (tg-group-bot)
Бот модерации работает «разведчиком»: пересылает в CRM сообщения из групп, которые вы включили
в 🔍 Группы → 🛡 Бот модерации (по умолчанию все выключены). Оба бота должны быть на одном сервере.
1. Один раз: `docker network create tgbots`.
2. Придумайте секрет (`openssl rand -hex 16`) и пропишите его: `FEED_TOKEN=` в `.env` CRM-бота,
   `CRM_FEED_TOKEN=` и `CRM_FEED_URL=http://crm:8090` в `.env` бота модерации.
3. Перезапустите оба бота: `docker compose up -d --build` в каждой папке.

## Каталог групп (этап 2)
- 🌐 Каталог (и `/catalog`): пользователь присылает ссылку на **открытую** группу или канал → бот проверяет её через Bot API
  (тип, число участников, дубли, суточный лимит) → пользователь выбирает нишу и город → карточка уходит администраторам.
- Администратор одобряет в 🔍 Группы → «📝 От пользователей»: группу берёт разведчик, канал читается без вступления.
- Каталог показывает группы по нишам и городу пользователя (или весь).
- 🎁 Бонус: за каждые N заявок (⚙️ Настройки, по умолчанию 5) из группы пользователя — +1 день 💎 ему.
- **Открытые каналы**: раз в 15 минут бот читает `t.me/s/<канал>`; пост становится заявкой, только если в нём есть контакт (@ник).
  Первый опрос канала лишь запоминает последний пост — старое не разбирается.

## Приглашения и передача заявок (этап 3)
- 👤 Профиль → 🤝 Пригласить друзей: личная ссылка `t.me/<бот>?start=ref_<id>`. Когда друг завершит настройку (ниши + город),
  оба получают +7 дней 💎 (один раз на друга). Дальше пригласившему идёт 20% от бонусных дней, которые друг зарабатывает за свои группы.
- 📨 «Коллеге» на карточке заявки: ввести ID или @username коллеги из бота — заявка придёт ему сразу (без задержки бесплатного тарифа)
  с подписью «Передал(а)». Если коллеги нет в боте — бот даст ссылку-приглашение. Лимит передач — в ⚙️ Настройки.

## Первооткрыватели, уровни, рейтинг (этап 4)
- 📊 **Заявки делятся поровну, без гонки по времени**: на каждую заявку берутся люди с наименьшим числом заявок за сутки,
  их число = ⌈людей ÷ заявок ниши за сутки⌉ (не больше лимита). Заявок много (например, 20 на 4 человека) — у каждого свои, разные,
  по 5; заявок мало — одну получают несколько, но по очереди: первым — автор группы, дальше тот, у кого уровень выше (при равных — у кого меньше заявок за сутки); остальные через 2 мин друг за другом
  (⚙️ Настройки). Платные — вперёд бесплатных, администраторы получают все.
- ⚡ **Право первооткрывателя**: заявки из группы, добавленной через 🌐 Каталог, всегда приходят её автору — сразу и мимо
  дневного лимита бесплатного тарифа (если подходят по его нише и городу).
- 🏆 **Уровни** по числу заявок из групп автора: 🌱 Новичок → 🔎 Разведчик (группа в каталоге) → 🥉 10 → 🥈 50 → 🥇 200 → 👑 1000.
  О повышении бот сообщает сам.
- 🏆 **Рейтинг** в 🌐 Каталог: лучшие авторы по моему городу или по всей России (администраторы не участвуют).

## Запуск
1. `cp .env.example .env`, заполните `BOT_TOKEN` (@BotFather) и `OWNER_IDS` (ваш Telegram ID).
   `TG_API_ID`/`TG_API_HASH` — с my.telegram.org (для аккаунта-разведчика; **отдельный номер**, не основной).
2. `docker compose up -d --build` (или локально: `pip install -r requirements.txt && python -m app.main`).
3. В боте: `/start` → ⚙️ Настройки → 👤 Аккаунты → ➕ Добавить аккаунт (код из Telegram, при необходимости пароль 2FA).
4. 🔍 Группы → «Искать сейчас». Одобряйте группы кнопкой «✅ Вступить».

База по умолчанию SQLite (`data/crm.db`); для PostgreSQL задайте `DATABASE_URL=postgresql+asyncpg://…`.
Сессии разведчиков хранятся в БД как строка — берегите файл базы.
